# MVP要件

## MVPとは

MVPは、顧客にとって価値があるかを確認できる、最小限の完成品です。

このプロジェクトのMVPは、請求書をアップロードすると、主要項目をJSONとして取得でき、読み取り結果の問題を警告できるシステムです。

## 誰の問題を解決するか

中小企業の経理担当者が、請求書を見ながら会計・支払用データへ手入力する負担と、転記ミスを減らします。

## 入力

- 日本語の請求書1件
- PDF、PNG、JPEG
- 1ファイルにつき請求書1件
- 1〜3ページ

## 出力

- 請求書番号
- 発行日
- 支払期限
- 取引先名
- 商品名
- 数量
- 単価
- 明細金額
- 小計
- 税額
- 合計金額
- 読み取り警告
- 元のページ番号と根拠箇所

## MVPに含めないもの

- 発注書や領収書
- 手書き文書
- Excel、CSV入力
- RAG、ベクトル検索
- AWSへの公開
- 会計ソフトへの自動登録
- 人の確認を一切必要としない完全自動処理

## 完成の判定

- 対象サンプル請求書をアップロードできる
- 抽出結果をJSONで取得できる
- 同じファイルを再投入しても重複登録されない
- 小計、税額、合計金額の不整合を警告できる
- 処理失敗の理由を確認して再実行できる
- 抽出値が元のどのページにあったか確認できる
- 正常系と異常系のテストがある

## 現在の仮定

最初の利用者は中小企業の経理担当者、最初の文書は日本語の請求書とします。実装中に、この仮定が不適切だと分かった場合は変更履歴を残して見直します。
